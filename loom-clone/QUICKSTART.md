# 🚀 Démarrage Rapide - Loom Clone

## Installation en 3 étapes

### Windows

1. **Installer** :
   ```
   Double-cliquez sur install.bat
   ```

2. **Lancer** :
   ```
   Double-cliquez sur run.bat
   ```

### macOS / Linux

1. **Installer** :
   ```bash
   ./install.sh
   ```

2. **Lancer** :
   ```bash
   ./run.sh
   ```

## Première utilisation

1. L'application s'ouvre avec une prévisualisation de votre webcam
2. Choisissez où placer la webcam sur votre écran
3. Cliquez sur "⚫ Démarrer l'enregistrement"
4. Faites votre présentation
5. Cliquez sur "⬛ Arrêter l'enregistrement"
6. Votre vidéo est dans le dossier `recordings/`
